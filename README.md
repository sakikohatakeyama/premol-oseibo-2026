# プレモル お歳暮・お年賀特集 2026｜酒のビッグボス 楽天市場店

ザ・プレミアム・モルツのお歳暮（2026）・お年賀（2027）ギフト特集ページです。

- `index.html` … 本番用ページ（HTML・CSS・JS を1ファイルにまとめています）
- `img/` … 公開時は一緒にアップしてください
  - `item-*.png` … 商品画像（背景を透過した切り抜きPNG）。BP5AG・BP3AG・BPF5S・BPF3S・BPCK3S・VM5S・VM4S・VM3S はサントリー公式の切り抜き画像、BPF4S・FJ3S・DMD3S はサントリー提供画像の白背景を透過処理したもの
  - `fv-hand-line1.png` … FVの見出し1行目「一年のありがとうに」の手書き文字（ご提供素材「一年の感謝に、少しいいビール-1.png」から切り出し）
  - `hero-beer.webp` … FVの切り抜きビール（ご提供素材・背景透過。PCは左側、スマホは右側に表示。タブレットでは非表示）
  - `hero-limited.png` … サントリー公式の缶＋グラス画像（限定醸造ブロック）
  - `logo-bigboss-2026.png` … ヘッダーのビッグボスロゴ（ご提供素材）
  - `bigboss-boss.png` … 吹き出しのアイコン（ご提供素材「ボス.png」）
  - `noshi-*.jpg` … ビッグボスのオリジナルのし（御歳暮・花柄お歳暮・お年賀）
  - `set-pm6b.jpg` … PM6B（ビッグボスのオリジナル箱）の商品写真。背景つきの写真のため切り抜きなし

## 構成（参考デザイン bigboss-oseibo-complete をもとに作成）
1. ヘッダー／ヒーロー（FVイメージ.jpg に合わせた赤背景・金の英字・手書き＋丸ゴシックの見出し・「お歳暮・お年賀特集」の枠＋ビール写真＋切り抜きギフトが流れる演出）。英字は Jost、見出しと枠は M PLUS Rounded 1c（Google Fonts）。PCはヘッダー（1400×74px）とFV（1400×600px）をそれぞれ1枚の絵として作り、画面幅に合わせて丸ごと拡大縮小（表示倍率を変えても見た目は変わらない）：「一年のありがとうに、いつもより、少しいいビールを。」
2. メニューボタン（スクロール追従。PCは横1列、スマホは2列×2段）
3. **ビッグボスのオリジナルのし**（のし無料・お歳暮2種・お年賀1種）※強みとしてヒーロー直後に配置
3.5 **PICK UP（独立ブロック）**：PM6B（楽天広告の掲載商品）・DMD3S
4. 贈る相手から選ぶ（3つの選び方）
5. マスターズドリーム 限定醸造（水泉動）＋水泉動入り4セット
6. 2027年 干支「未」デザイン缶（BP5AG を大きく＋干支缶入り4セット）
7. 商品一覧（12セット）：絞り込み「すべて／定番プレモル／限定醸造入り／干支・飲み比べ／ファミリー」、並び替え「価格・本数」
8. 締め／フッター／スマホ下部の固定ボタン

PCのメインコンテンツ幅は1000px（`:root` の `--cw` で一括変更できます。ヘッダーとFVは別管理）。

商品データ（価格・URL・中身）は `index.html` 下部の `const products=[...]` にまとめています。

## 公開前に差し替える・確認する箇所
- **DMD3S の商品ページURL・価格・発売日**：`index.html` の `const products` 内、DMD3S の `url:null`（楽天の商品ページID）・`price:null`（税込価格）・`when:null`（例：'2026年10月27日発売'）を書き換えてください。限定醸造ブロックと商品一覧の両方に反映されます。**PICK UP枠のDMD3S**は `<!-- ▼ PICK UP 2：DMD3S -->` のコメントに沿って別途書き換えてください
- 価格・発売日・在庫は変わることがあります。公開直前に商品ページと照合してください
