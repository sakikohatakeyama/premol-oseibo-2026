# プレモル お歳暮・お年賀特集 2026｜酒のビッグボス 楽天市場店

ザ・プレミアム・モルツのお歳暮（2026）・お年賀（2027）ギフト特集ページです。

- `index.html` … 本番用ページ（HTML・CSS・JS を1ファイルにまとめています）
- `img/` … 公開時は一緒にアップしてください
  - `gift-*.jpg` … サントリー提供のギフト画像（11点、幅900pxに縮小）
  - `noshi-oseibo-formal.jpg`（御歳暮）・`noshi-oseibo-hana.jpg`（お歳暮・花柄）・`noshi-onenga.jpg`（お年賀・未） … ビッグボスのオリジナルのし
  - `set-pm6b.jpg`・`visual-*.jpg` … 酒のビッグボス楽天市場店の商品ページの画像（PM6Bはサントリー提供画像なし）

## 構成
1. FV：メインコピー「一年のありがとうに、いつもより、少しいいビールを。」＋**オリジナルのし帯（選べる3種・無料）**＋限定醸造・干支缶への導線
2. ビッグボスのオリジナルのし（お歳暮2種：御歳暮・花柄お歳暮／お年賀1種：未）※ビッグボスの強みとしてFV直後に配置
3. 贈る相手から選ぶ（定番／限定醸造入り／干支デザイン）→ ボタンを押すと商品一覧が絞り込まれた状態になります
4. マスターズドリーム 限定醸造（水泉動入りの VM3S・VM4S・VM5S・DMD3S）
5. 2027年 干支「未」デザイン缶（BP5AG・BPCK3S・PM6B・BP3AG）
6. 商品一覧（12セット）：絞り込み「定番プレモル／限定醸造入り／干支・飲み比べ」、並び替え「価格・本数」
7. 締めのブロック

## 公開前に差し替える・確認する箇所
- **DMD3S の商品ページURL・価格・発売日（2か所）**：`<!-- ▼ DMD3S：... -->` のコメントがある限定醸造ブロックと商品一覧のカードに入れてください。商品一覧のカードは、URLを入れたら `<span class="btn go is-soon" ...>` を他の商品と同じ `<a class="btn go" href="..." target="_blank" rel="noopener">商品ページを見る</a>` に、`data-price=""` に価格を入れてください
- 価格・発売日・在庫は変わることがあります。公開直前に商品ページと照合してください
